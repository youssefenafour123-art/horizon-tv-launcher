# Optional photo wallpapers (Nano Banana Pro)

The launcher paints its own live wallpaper. If you want photo-real ones instead,
generate these in Gemini (Nano Banana Pro), 16:9, 4K, and save them in this folder
with exactly these names. Any phase that has a photo uses it (with a slow
Ken Burns drift). Phases without a photo keep the painted live sky.

Use the same seed/scene description for all eight so the place stays identical
and only the light changes. Base scene (paste first, then add the line per phase):

> Cinematic wide landscape photograph, 16:9, a calm Moroccan scene: sand dunes in
> the foreground, a lone palm grove and a small white mosque with a square
> Maghrebi minaret in the middle distance, the Atlas mountains far behind.
> Lots of empty sky in the upper half for overlaying UI text. No people, no text,
> no logos. Shot on a full-frame camera, 24mm, natural colors, high dynamic range.
